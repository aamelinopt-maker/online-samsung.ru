# online-samsung.ru

Четыре версии карточки товара Samsung.

- [Открыть карточку 1](https://aamelinopt-maker.github.io/online-samsung.ru/карточка%20товара/index.html)
- [Открыть карточку 2](https://aamelinopt-maker.github.io/online-samsung.ru/карточка%20товара%202/index.html)

Общие фотографии, шрифты, стили и скрипты сохранены в `assets/`. Видео загружаются с оригинального CDN страницы online-samsung.ru и требуют интернет.

Корзина, избранное и формы работают как локальная демонстрация.

Во все HTML-страницы добавлен robots meta `noindex, nofollow`.

Новые варианты с согласованным дизайном клиента:

- [Вариант 3 — три колонки](https://aamelinopt-maker.github.io/online-samsung.ru/карточка%20товара%203/index.html)
- [Вариант 4 — две колонки](https://aamelinopt-maker.github.io/online-samsung.ru/карточка%20товара%204/index.html)

В новых вариантах нет загрузки Drupal, jQuery, Slick и старых общих
CSS-пакетов. Используемые стили собраны в page.css; интерактивность
работает самостоятельными скриптами. Основной контент показывается
после подготовки раскладки и шрифтов. Новая тема включена в исходном HTML.
Фотографии товаров загружаются с online-samsung.ru с локальным резервом,
видео — с исходного content.24ttl.stream по мере появления в описании.
Прежние варианты 1 и 2 сохранены. Откат публикации — revert коммита,
добавляющего варианты 3 и 4.
