# online-samsung.ru

Две версии карточки товара Samsung.

- [Карточка 1](карточка%20товара/index.html)
- [Карточка 2](карточка%20товара%202/index.html)

Общие фотографии, шрифты, стили и скрипты сохранены в `assets/`. Видео загружаются с оригинального CDN страницы online-samsung.ru и требуют интернет.

Откройте корневой `index.html` или разместите содержимое репозитория на статическом хостинге. Корзина, избранное и формы работают как локальная демонстрация.

Во все HTML-страницы добавлен robots meta `noindex, nofollow`.
