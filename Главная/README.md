# Главная Samsung

Статическая версия главной страницы в дизайне samsung-site-client.

[Открыть страницу](https://aamelinopt-maker.github.io/online-samsung.ru/Главная/)

- Один CSS-файл; самостоятельный JavaScript без старых библиотек.
- Локальные шрифты и изображения, адаптивные версии главного баннера.
- Стрелки баннера удалены на компьютере и телефонах.
- Вкладки, FAQ, меню, поиск и демонстрационные корзина/избранное работают в браузере.
- Два сохранённых отзыва Яндекса показываются с датой снимка; PHP-обновление в Pages не используется.
- Контент магазина сохранён. Заказ, оплата и авторизация требуют сайта магазина.

Архивы, исходные выгрузки, скриншоты и инструменты сборки в публикацию не включены.
